# Quickmd UI 润色说明

- **任务：**在刘海下快速打开便签，直接写 Markdown。
- **主动作：**点开面板后写字；待办项可以直接勾选。
- **设计方向：**保留 macOS 备忘录的暖纸面和清楚的标题层级，界面继续保持轻量，没有工具栏。
- **设备限制：**面板固定为 330×285pt；内容较长时在编辑区内滚动；浅色和深色跟随系统。
- **关键状态：**就绪、未保存、已保存；待办未勾选和已勾选；浅色和深色。
- **本次调整：**状态栏文字从 11px 提到 12px，状态栏从 24px 提到 28px 并提高文字对比；待办框增加手形指针和悬停反馈；删除线文字从过淡的灰色调到仍清楚可读的次要文字色。
- **验收重点：**状态文字在 330×285pt 下能读清；勾选框看得出能点；待办已勾选和未保存状态能区分；长内容滚到底后不被状态栏遮挡。

## 视觉检查

使用临时编辑器预览，按 330×285pt 视口、2 倍像素检查浅色、深色、未保存、勾选框悬停和滚到底状态。截图检查没有横向溢出、控制台错误、图片加载问题或可读性提示。独立视觉评审 1 轮，不打分；删除线对比度问题已修，首屏底部露出的半行文字确认属于可滚动内容，滚到底后完整可见。

本次没有启动实际 App，以免诊断样例写进用户当前便签；因此原生窗口阴影未复核。没有删减产品文案，也没有改动功能逻辑。
