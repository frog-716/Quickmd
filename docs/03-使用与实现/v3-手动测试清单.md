# Quickmd v3 手动测试清单

> 用途：自己一条条点过去，确认每个功能都正常。
> 用法：先构建并启动 App（`cd Quickmd && ./build.sh && open Quickmd.app`），
> 然后把鼠标移到屏幕顶部刘海中央唤出面板，从上往下逐条测。

## 已知边界（不是 bug，是有意的取舍）

- **只能存纯 .md**：不做富文本、表格、图表。这是刻意的取舍——文件即真相源。
- **不抢辅助功能权限**：用 30Hz 轮询读鼠标位置，所以系统设置里不会多一条授权提示；代价是触发必须「鼠标真的碰到刘海」。
- **不能拖 .md 进窗口**：用菜单 ⌘O 打开。
- **超大文档**：分块渲染，1286 块的大文档内存只比小文档多约 5MB。
- **面板尺寸固定 330×285**：刘海下面的空间就那么大。
