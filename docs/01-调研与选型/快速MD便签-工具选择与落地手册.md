# 快速 MD 便签：工具选择与 10 分钟落地手册（v2 已换掉 VS Code）

> 承接前几轮评估。目标：快捷键（尽量支持滑向右下角）呼出/退出的 Markdown 便签；数据继续沉淀在备忘录；极简、轻量、不过程序坞。
> **v2 变更：编辑器由 VS Code 换成 Typora。** 原因：Typora 所见即所得（敲 `# ` 即渲染，无分栏）= 飞书云文档同款编辑手感；且 2026 年已证实为原生 Cocoa + 系统 WebKit 应用（非 Electron），内嵌框架只有 Sparkle，启动 <1 秒。

## 先把两个问题讲清楚

**「退出时内容怎么处理」三种意思：**
1. **关闭即暂存**：按 Esc 或点外面，便签收起，内容躺在一个 .md 文件里；什么时候进备忘录、进哪条，你事后手动决定。零风险，零脚本。
2. **退出即追加**：关闭的同时，系统自动把内容追加进备忘录里你选中的那条 note。省一步，但依赖「追加 Markdown 到备忘录」这个指令可靠——需先验证。
3. **只当草稿箱**：永远只存在 .md 里，备忘录靠你手动整理。等于备忘录永远滞后，不适合你「减熵」的诉求。

**「暂存 .md 放哪」两种意思：**
- **本地文件夹 `~/Documents/QuickMD/`**：只在这台 Mac 上，Time Machine 兜底。不会出现「备忘录里一份、.md 里一份」两个真相互相打架。iPhone 看不到这些草稿。
- **iCloud Drive 目录**：iPhone 也能读这些草稿；代价是版本可能和备忘录分叉——除非你严守「.md 只是草稿、备忘录才是成品」。

**给极简原则的答案：本地 `~/Documents/QuickMD/` + 关闭即暂存。** 这是唯一不会制造双真相源的组合。

## 编辑器选型：为什么是 Typora

你的诉求拆开是：轻量、界面干净（飞书云文档感）、MD 编辑、快捷键呼出、跟 .md 文件管道兼容。候选对比（2026-10 核实）：

| 候选 | 价格 | 编辑体验 | 技术形态 | .md 管道兼容 | 结论 |
|---|---|---|---|---|---|
| **Typora 1.14** | ¥89 / $14.99 买断，3 设备，15 天试用 | **所见即所得，无分栏，最像飞书** | 原生 Cocoa + 系统 WebKit（2026-07 拆包证实非 Electron） | ✅ 直接编辑磁盘 .md | **选它** |
| MarkText | 免费开源 | 类似 Typora 的所见即所得 | 开源跨平台 | ✅ | 不想付费的备选，完成度略低 |
| iA Writer | $49.99 买断 | 极简写作，语法高亮非实时渲染 | 原生 Swift | ✅ | 贵，是「写作工具」不是「文档感」 |
| Bear 熊掌记 | 免费 / Pro $29.99/年 | 颜值最高 | 原生 Swift | ❌ **自有数据库，不是磁盘上的 .md** | ❌ 违背单一真相源 |
| Obsidian | 免费 | 强大但重 | Electron | ✅ | 违背「轻量」 |

**为什么不是 Bear**：Bear 的笔记存在它自己的 SQLite 库里，你要么把 Bear 当新沉淀库（与「数据留在备忘录」直接冲突，推翻前面全部结论），要么每次编辑完手动导出 .md 再走管道（多两步，且引入第二个库）。Typora 直接编辑磁盘上的 .md，管道一步不变。

**为什么不是飞书云文档本身**：飞书是云服务 + 独立 App，数据存在飞书云上，和你的备忘录沉淀库完全断裂——熵增本增。你要的是它的「编辑手感」，Typora 给得起。

## 最终链路（换 Typora 后）

1. **呼出**：Shortcuts「打开暂存便签」=「打开文件」`~/Documents/QuickMD/scratch.md`，.md 默认打开方式设为 Typora，快捷键绑 ⌥⌘N。
2. **编辑**：Typora 所见即所得——敲 `# ` 是标题、`- ` 是列表、⌘B 加粗，屏幕上就是最终排版（飞书同款逻辑）。引用、表格、代码块全支持。
3. **退出**：⌘W 关窗即存盘（Typora 默认行为）；Esc 在 Typora 里是退出专注模式，习惯改用 ⌘W。
4. **滑向右下角（妥协方案）**：系统设置 → 桌面与程序坞 → 屏幕边角，右下角 = 「快速备忘录」：滑动捕获交给原生（富文本，无所谓格式），MD 编辑走 ⌥⌘N。真要在 MD 上也滑动，只有 BetterTouchTool 一条路（见 C 方案）。
5. **回写**：选中备忘录目标 note → Shortcuts「追加 Markdown 到备忘录」→ 粘贴内容。只追加、不原地替换（最稳写回路径）。

## 硬性红线（必须遵守）

1. NoteStore 是唯一真相源，.md 只是草稿；禁止建长期双向同步文件夹。
2. 写回只用「追加 Markdown 到备忘录」；`set body` 原地替换仅限无附件 note 且验证后启用。
3. 不关 SIP、不注入 dylib、不让任何第三方工具直写 NoteStore.sqlite。
4. Fn+Q 快速备忘录保持原生，MD 便签只管「重编辑」场景，不追求全量替代。

## 10 分钟落地清单

- [ ] 装 Typora（15 天试用，再决定买不买断 ¥89）：typora.io
- [ ] Finder 里右键 `~/Documents/QuickMD/scratch.md` → 显示简介 → 打开方式选 Typora → 点「全部更改」
- [ ] Shortcuts 新建「打开暂存便签」→ 加「打开文件」选 scratch.md → 详细信息里绑全局快捷键 ⌥⌘N
- [ ] 系统设置 → 桌面与程序坞 → 屏幕边角 → 右下角 = 快速备忘录
- [ ] Shortcuts 新建「追加到备忘录」→ 加「追加 Markdown 到备忘录」动作（首次运行会请求授权，点允许）
- [ ] 用一条测试 note 跑一次完整闭环：⌥⌘N → 写 → ⌘W → 选中 note → 追加 → 确认样式
- [ ] 用满 15 天试用再决定是否买断；不满意就走免费备选 MarkText，其余步骤不变
