# Quickmd 项目历史决策

> 本文只记录**「为什么这么做」的关键决策依据**——尤其是那些从代码里看不出来的理由
> （比如 license 风险、为什么用轮询而不是全局监听）。当前产品形态看 `README.md` 和 `MAP.md`。
>
> 记录时间：2026-10-21 至 10-23。

## 阶段一：备忘录改 Markdown 可行性（只读调研）

**背景**：用户想让自己积攒的备忘录内容按 Markdown 格式流转，不想换 App。

- **Career App**（~/Projects/Career）：迁移可行、低风险。历史正文即合法 MD，零迁移；最大风险是渲染 MD 后的 XSS 面。
- **系统备忘录 Notes.app**：直改本体不可行（Apple 签名 / SIP / 闭源三重锁死）。但备忘录已内置官方 MD 积木（导入 .md、导出 .md、快捷指令），「内容按 MD 流转」可行。
- **中间层对抗性压力测试**：备忘录窗口内 MD 编辑物理不可行（无扩展点）。可行形态 = 平行 MD 表面 + 单向桥。三个崩盘点：原地写回最脆（可靠写回=追加）、Quick Note 捕获永远在 MD 循环外。

**结论沉淀**：用户核心诉求收敛为「MD 编辑体验 + 数据本地单一真相源」。

## 阶段三：NotchNotes 评估 → 自研 MVP

- NotchNotes 92 stars、架构匹配，但 **license: null** → fork 分发有法律风险 → 自研
- 硬件实测纠正了「无刘海」的错误结论：MacBook Air M5，`safeAreaInsets.top=32pt`，内建屏 1470×956
- 快速备忘录窗口实测尺寸 **330×285pt**（截图标尺反推），作为面板尺寸常量

**MVP 关键架构决策**（均参考 NotchNotes 后自研）：

1. **30Hz 轮询 `NSEvent.mouseLocation`**，不用全局 mouseMoved 监听 → 零辅助功能权限。这是整个方案「不打扰、免授权」的根基。
2. **hover 被动预览 vs 点击激活**：hover 只 `orderFrontRegardless()` 不抢键盘焦点；点击才 `allowsKeyActivation=true` 并「钉住」（鼠标移开不收起）。
3. **停留区判断**：必须有，否则鼠标从刘海移进面板的瞬间就被判定「离开热区」而收起。
4. **刘海宽度 = frame.width − auxiliaryTopLeftArea.width − auxiliaryTopRightArea.width**（两者是 Optional，必须解包）。

## 阶段四：v2 Markdown 所见即所得

- 架构：**分块 WYSIWYG**。md → parse → blocks → renderBlock → HTML → contenteditable；保存时 DOM 反序列化回 md。
- 核心设计：**只有「需要变形」时才重渲染**（敲前缀/工具栏/勾任务），普通打字不动 DOM → 光标不跳；重渲染后用文本偏移恢复光标。
- 修过的往返 bug：列表序列化取错子元素、文本节点守卫缺失、代码块语言标签丢失。
- XSS 防护：HTML 转义 + 链接协议白名单（拦 javascript:/data:）+ 属性转义。
- **块间连接从 `\n` 改 `\n\n`**：原实现存出的文件段间无空行，在标准 MD 渲染器里段落会并成一块。

**内存实测**（footprint 差分）：日常 ≈37MB（主进程 20MB 固定底座 + WebContent 17MB）；72KB/1286 块也只 42MB。

## 阶段五：用户实测反馈修复（v2.1）

- **位置 bug**：面板顶边贴屏幕顶被刘海盖住工具栏 → 改为贴刘海下沿（`maxY − safeAreaInsets.top − height`）。
- **打不了字 bug**：WKWebView 铺满面板，点击落在 WebView 上，容器 mouseDown 不触发 → `activatePanel()` 从不执行 → 面板停在 `canBecomeKey=false` 预览态。**MVP/v2 的自检走显式激活路径，覆盖不到这条真实用户路径** —— 教训：自检必须覆盖真实用户路径。修复：`EditorWebView` 子类在 mouseDown 里先激活再 super。
- 新增 `--clicktest` 诊断开关（合成鼠标事件走 AppKit 真实分发，无需辅助功能权限）。

## 沉淀的工程教训

1. **自检要覆盖真实用户路径**——显式调用的自检链路通了，不代表用户点击时通。
2. **判定 App 是否真跑过不能靠 diff 文件**——pkill(SIGTERM) 不触发 flushSave，要用诊断开关打日志。
3. **跨目录迁移前先清构建缓存**——`.build` 里记着旧绝对路径，搬完必须 `rm -rf .build` 重建。
4. **沙箱内 mv 到沙箱外有竞态**——文件可能丢；重要文件迁移后立即核对清单。
5. `open -a` 不透传环境变量，调试日志要直接跑二进制。
